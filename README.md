# dotProject

dotProject is a legacy PHP project management application. This repository is a maintained fork focused on modernization and security hardening.

## Quick start

1. Clone the repository and change into it:

```bash
git clone <repository-url>
cd dot
```

2. Start services:

```bash
docker-compose up -d
```

3. Open http://localhost:8000 and follow the installation wizard.

For full, copy-paste commands and troubleshooting steps, see the quick start documentation in the `docs` folder.
